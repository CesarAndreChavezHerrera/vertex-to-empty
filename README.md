# vertex-to-empty
Blender 5.2 addon for binding an Empty object to a specific geometry vertex group.

This addon automates a simple yet tedious task: binding an Empty object to a specific geometry vertex group.

Features:
- Automatically creates a new Vertex Group from the selected vertices.
- Spawns a new Empty object using the exact same name as the vertex group.
- Applies and configures a Constraint targeting the geometry constrained strictly to the newly created group.

Perfect for rigging workflows, attaching props, and speeding up repetitive object-to-mesh setups.
